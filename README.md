# birthday_alerts

Программа для отслеживания дней рождения и получения уведомлений о предстоящих событиях.

## Использование

Запуск программы осуществляется из командной строки:

```bash
python3 birthday_alerts.py [command]
```

## Команды

| Команда | Описание |
|---|---|
| `all` | Показать все дни рождения, отсортированные по дате ближайшего события. |
| `add` | Добавить новый день рождения. |
| `edit` | Редактировать существующий день рождения. |
| `next` | Показать ближайший день рождения. |
| `check` | Проверить дни рождения и отправить уведомления. |
| `remove` | Удалить день рождения. |
| `add_to_autorun` | Добавить программу в автозапуск. |
| `remove_from_autorun` | Удалить программу из автозапуска. |

## Пример

Показать все дни рождения:

```bash
python3 birthday_alerts.py all
```

Добавить новый день рождения:

```bash
python3 birthday_alerts.py add
```

Проверить ближайший день рождения:

```bash
python3 birthday_alerts.py next
```
